# Compito TPSI

Progetto web base creato da zero con HTML, CSS e JavaScript.

## Come usare

1. Apri il file `index.html` nel browser, oppure avvia un server locale:

```bash
cd /workspaces/compito-tpsi
python3 -m http.server 8000
```

2. Apri il browser all'indirizzo:

`http://localhost:8000`

## Contenuto

- Layout moderno e responsivo
- Tema chiaro/scuro
- Sezioni informative e footer con form
- JavaScript per aggiornare la data e gestire l'interazione

## Struttura

- `index.html` — struttura della pagina
- `styles.css` — stili e layout
- `script.js` — interazioni JavaScript
